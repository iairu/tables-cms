# Tauri Icons

Place your app icons in this directory. You'll need:

## Required Icons

- `icon.icns` - macOS icon (512x512 source)
- `icon.ico` - Windows icon (256x256 source)
- `32x32.png` - 32x32 pixels
- `128x128.png` - 128x128 pixels
- `128x128@2x.png` - 256x256 pixels

## Generating Icons

You can use the Tauri CLI to generate icons:

```bash
npm run tauri icon /path/to/source.png
```

Or use an online icon generator.

## Temporary Placeholder

For development, you can copy any PNG image and rename it to the required sizes.
